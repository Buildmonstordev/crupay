# crupay Dashboard

The crupay dashboard — Next.js 16 App Router with React 19, TypeScript, and Tailwind CSS v4.

## Getting Started

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Routes

- **Dashboard:** `http://localhost:3000/dashboard`
- **Lite App (Mobile):** `http://localhost:3000/lite`
- **Admin Panel:** `http://localhost:3000/admin`
